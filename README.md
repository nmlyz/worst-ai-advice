A tiny program that writes one line of deliberately terrible advice to a
text file. The line is a single sentence of at most 140 characters: advice
an AI assistant could plausibly give, specific enough to follow, and bad
enough to regret following.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
